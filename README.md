# つづきから

自分専用の動画アプリ(YouTube アプリに近い操作性のウェブアプリ)。

- 登録チャンネルの新着を一覧で見る(YouTube で登録していた 65 チャンネルを最初に取り込み済み)
- **途中で止めた位置を覚えて、次に開くとそこから再開**(スマホとパソコンで共有)
- **字幕はいつも出さない**
- ダブルタップで 10 秒戻る/進む、再生速度、全画面、画面を移っても小さい再生窓で流し続ける
- 「けさの便」: 毎朝 6:00(設定で変更可)に、前の日の朝からの新着をひとまとめにして見せる
- 検索・チャンネルのページ・関連動画・あとで見る・履歴

公開先: https://neitianguang209-oss.github.io/tsuzuki/

## 広告について

動画は YouTube 公式の埋め込みプレーヤー(youtube-nocookie)で流しています。広告を消す・飛ばす仕組みは入れていません(YouTube の決まりで禁止)。広告の出方は、ふだん Chrome で YouTube を見ているときと同じになるはずです。広告の「スキップ」を押したいときは、再生画面の「…」→「YouTube の画面を直接さわる」。

## しくみ

| 部分 | 中身 |
|---|---|
| 画面 | `index.html` + `src/*.js`(React 18 + htm を esm.sh から。ビルド不要) |
| 自分のデータ | Supabase の表 `tsuzuki_channels / videos / progress / later / hidden`。入口は関数 `tsuzuki_api(合言葉, 操作, 中身)` だけ(表は anon から閉じている) |
| YouTube の公開情報 | Edge Function `tsuzuki`(新着は各チャンネルの RSS、検索・関連動画・チャンネルの動画一覧は YouTube の公開ページと同じデータ) |
| 合言葉 | じぶんノート・就活アプリと共通(`jibun_access`)。同じ github.io なので、どれかで入れてあれば自動で使う |

- 新着の取り込み: アプリを開いたとき、最後の取り込みが 15 分以上前なら自動で取り込み直す。右上の ↻ でも取り込める。
- 動画の長さは、チャンネルの「動画」「ライブ」の一覧から少しずつ埋める(取り込みのたびに数チャンネルずつ)。
- 端末にも控えを持つので、通信できないときも前回の一覧は開ける。マイページ →「データを書き出す」で JSON に保存できる。

## 使い始める(iPhone)

1. パソコンで `powershell -ExecutionPolicy Bypass -File tools\copy-link.ps1` を実行 → 合言葉入りのリンクがコピーされる
2. LINE の自分用トークなどで iPhone に送り、**Chrome で開く**(合言葉が保存される)
3. 最初の1本だけ、動画の ▶ を直接押して再生する(iPhone の決まりで、最初の1回は動画そのものをタップする必要がある)
